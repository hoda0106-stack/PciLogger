# مراقب الأبراج — TP-Link Archer MR505

تطبيق أندرويد يقرأ من راوترك معلومات البرج المتصل به كل بضع ثوانٍ ويسجّلها:
**PCI، EARFCN، الباند، رقم البرج (eNB)، RSRP، RSRQ، SNR، CQI** — ويرتّب الأبراج من الأفضل إلى الأسوأ حسب متوسط SNR.

التطبيق **للقراءة فقط**، لا يغيّر أي إعداد في الراوتر.

## كيف يعمل
- يفتح صفحة الراوتر `https://192.168.1.1` داخل التطبيق.
- تسجّل الدخول بنفسك بكلمة مرور الراوتر (التطبيق لا يحفظها).
- يقرأ بيانات الخلية من نفس الواجهة الداخلية التي يستخدمها الراوتر (block 151 – LTE_SERVING_CELL_INFO)، وهي بيانات لا تظهر في واجهة الراوتر العادية.

## بناء ملف APK

### الطريقة 1: GitHub (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على github.com (يمكن أن يكون Private).
2. ارفع محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
3. افتح تبويب **Actions** — سيبدأ البناء تلقائياً (حوالي 3–5 دقائق).
4. افتح آخر تشغيل ناجح ← قسم **Artifacts** ← نزّل `PciLogger-apk` وفكّ الضغط لتحصل على `app-debug.apk`.

### الطريقة 2: Android Studio
افتح المجلد في Android Studio ← Build ← Build APK(s).

## الاستخدام
1. ثبّت الـ APK على الجوال (اسمح بالتثبيت من مصادر غير معروفة).
2. اتصل بشبكة الواي فاي التابعة للراوتر.
3. افتح التطبيق وسجّل الدخول في صفحة الراوتر بالأسفل.
4. اضغط **ابدأ**. غيّر الفترة بزر «كل … ث».
5. حرّك الراوتر بين أماكن مختلفة في البيت، وراقب أي برج/مكان يعطي أفضل SNR.
6. **تصدير CSV** يحفظ السجل كاملاً لفتحه في Excel أو أداة أخرى.

## ملاحظات
- SNR يرسله الراوتر مضروباً في 10، والتطبيق يقسمه تلقائياً.
- رقم eNB = Cell ID ÷ 256، ويفيد في معرفة أي خلايا تتبع نفس البرج.
- مع تجميع الترددات (LTE+) تظهر خليتان: الرئيسية (PCC) والمجمّعة (SCC).
- قفل البرج (PCI Lock) غير مدعوم في فيرموير هذا الراوتر، لذلك التطبيق يراقب ولا يقفل.
